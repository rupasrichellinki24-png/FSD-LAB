About HTML

HTML stands for HyperText Markup Language. It is the standard language used to create web pages.

HTML uses different tags to define the structure of a webpage. It can be used to add headings, paragraphs, images, links, lists, tables and other elements.

HTML documents are displayed by web browsers such as Google Chrome, Microsoft Edge and Mozilla Firefox.

Uses of HTML

  • Creating web pages
  • Adding images
  • Creating hyperlinks
  • Designing web page structure
